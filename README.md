# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

A ride-pooling MVP for Dhaka's three-wheeled "Teslas". Passengers (Nusrat, Rafiq, Shirin) request rides. Compatible requests share a Tesla, and each passenger pays their own discounted fare. The driver (Jashim, with his 3-seat Tesla **Bullet**) runs the trip from arrival to drop-off.

🚧 Work in progress. The design comes first: see [docs/DESIGN.md](docs/DESIGN.md) for the assumptions, matching rule, fare model, lifecycle, schema and concurrency strategy.
